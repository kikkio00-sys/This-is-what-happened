# V0.1 scope

## Included
Startup and Commissioning, Headquarters, Visible Privacy, typed Experience Registry, placeholder experience pages, security/privacy scaffolding, documentation, and testing foundations.

## Excluded
Live integrations, authentication provider, database provider, payments, affiliate systems, final artwork, native apps, WebGL, analytics, trackers, and third-party embeds.

## Definition of done
The app installs, builds, typechecks, lints, passes unit/component tests, runs Playwright smoke tests when browsers are available, provides usable commissioning, routes completion to Headquarters, supports mobile and keyboard navigation, respects reduced motion, contains no secrets, and documents V0.1 boundaries.
